How to Publish This Site Live

  1. Create a GitHub repository named data-analytics-portfolio.
  2. Upload the contents of the Portfolio_Website folder to the repository root.
  3. In GitHub, go to Settings → Pages.
  4. Set source to Deploy from a branch, then select main and /(root).
  5. Your live link will be:
    https://YOUR-GITHUB-USERNAME.github.io/data-analytics-portfolio/
